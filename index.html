💡 Antes de cambiar un proceso, lee esto
Renombrar un proceso
Qué significa: cambiar el nombre manteniendo el mismo código.
Qué hacer: hazlo sin miedo. La Matriz y las fichas mostrarán el nombre nuevo solas, al recargar.
Crear un proceso nuevo
Qué significa: añadir un proceso que no existía.
Qué hacer: dale siempre un código nuevo. No afecta nada de lo existente.
Eliminar un proceso
Qué significa: quitarlo del Inventario.
Qué hacer: si tenía fichas o indicadores, quedarán huérfanos y aparecerán en morado (🚫). Después hay que reasignarlos o archivarlos. Si no tenía nada, desaparece sin más.
⛔ Reutilizar un código
Qué significa: usar el código de un proceso eliminado para un proceso distinto.
Qué hacer: no lo hagas. El aplicativo no puede distinguirlo de un renombrado, y mostraría el nombre nuevo junto a indicadores que miden el proceso anterior. Un proceso nuevo lleva siempre un código nuevo.

Haz los cambios desde este aplicativo y no directamente en QuintaDB: así el sistema puede avisarte en el momento.

Para renombrar, mover, dividir, fusionar o retirar un proceso. Te guía paso a paso y te muestra a qué afecta antes de cambiar nada.

🔧 Renumerar o renombrar un proceso — úsalo después de cambiar un código o un nombre aquí arriba
¿Para qué sirve?
Cuando cambias el código o el nombre de un proceso en este inventario, el cambio no llega solo a la Matriz de indicadores ni a las fichas: cada indicador guarda una copia del nombre del proceso. Esta herramienta reemplaza el texto viejo por el nuevo en todas las tablas de una sola vez.

Ejemplo
El proceso M01.05.04 Tutoría, asesoría y consejería pasa a ser M01.05.03.
Escribes M01.05.04 en «Código actual» y M01.05.03 en «Código nuevo».
La herramienta lo corrige en todos los registros donde aparece, y respeta los sufijos: M01.05.04.01 queda como M01.05.03.01.

Si no lo usas, el Inventario dirá 03 y la Matriz seguirá diciendo 04. Los indicadores quedarían apuntando a un proceso que ya no existe con ese código.

También sirve para nombres. Pega el texto completo viejo en «actual» y el nuevo en «nuevo».

Cómo se usa con seguridad
1. Descarga el Excel del Inventario y de la Matriz, por si acaso.
2. Pulsa Buscar y revisa cuántos registros cambiarán.
3. Si el número cuadra, pulsa Reemplazar. No se puede deshacer.

Calcular el valor real con la fórmula del indicador
📐 Fórmula del % de avance: (valor alcanzado − referencia) ÷ (meta − referencia) × 100. Funciona para indicadores donde subir es mejor y donde bajar es mejor. 100% = se alcanzó la meta; 0% = sin avance respecto a la línea base.

Qué mide: cuánto se logró respecto a la mejora proyectada, no el valor absoluto alcanzado. Es decir, evalúa el grado de cumplimiento sobre la tasa de incremento programada.

Ejemplo (Escuela Profesional de Ingeniería Informática):
Línea base: 0,70 · Meta programada: 0,90 → la mejora proyectada es 0,20.
Al corte del 31 de julio de 2026 la gestión real alcanzó 91,18 % (0,91), es decir una mejora efectiva de 0,21 sobre la línea base.
% de avance = 0,21 ÷ 0,20 × 100 = 105 %
Supera el 100 % porque la mejora lograda fue mayor que la proyectada para el periodo.
